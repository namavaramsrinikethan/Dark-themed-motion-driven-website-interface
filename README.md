# Dark-themed-motion-driven-website-interface
Designed and prototyped a dark-themed, motion-driven website interface in Figma, focusing on immersive visuals, smooth interactions, and systemized layout structure.
The interface uses a black background UI with animated left-scrolling slides, enhanced through subtle motion and depth to create a modern, high-contrast browsing experience. Particular attention was given to timing, spacing, and visual hierarchy to ensure clarity while maintaining a premium aesthetic.

Design & prototyping highlights:
• Built scalable layouts using Grids and Auto Layouts for consistency and responsiveness
• Applied a structured typography system, strokes, and spacing to strengthen hierarchy and readability
• Implemented Figma prototyping interactions using Delay, Linear, and Smart Animate with refined timing control
• Designed smooth left-scroll animations to guide user attention and improve content flow
• Used Layer Blur effects to introduce glow and brightness, adding visual depth and focus
• Integrated a 3D element via Spline, enhancing the hero section and overall visual engagement
• Leveraged Unsplash and Iconify plugins for efficient asset management and consistency
• Published an interactive web preview using Anima, enabling real-time experience beyond static screens
This project explores how motion, contrast, and layered visuals can elevate user experience while remaining clean, intentional, and usable.
